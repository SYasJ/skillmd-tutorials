# skill.md tutorials

Code, prompts and files from the hands-on tutorials on the **[skill.md](https://www.youtube.com/channel/UCMQcMb_sp9gmMCYzhHRaS8g)** YouTube channel.

**One folder per episode, numbered in the order they come out.** The episode number is shown in the bottom-left of every video and on its end card (`→ ep001`), and the video description links straight to its folder.

| Ep | Date | Video | Folder |
|---|---|---|---|
| 001 | 2026-10-22 | Ollama Tutorial: A Free Local AI Built This Game in 3 Prompts — _link added when it goes live_ | [`ep001-ollama-local-ai-game/`](ep001-ollama-local-ai-game/) |

Each folder has its own README: what the video shows, every command and prompt in order, the files the AI produced (unedited), and the licenses of the tools and models used.

Everything in a folder is what we actually ran and what the AI actually produced. Check each tool's and model's license before commercial use.

The hands-on, show-every-step part of these tutorials is inspired by **[FreeAIVault](https://www.youtube.com/@FreeAIVaultTV)**.
